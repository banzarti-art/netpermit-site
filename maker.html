    How codes work

    • One phone only. Works on that phone and no other, so it cannot be passed on. It never expires. You need that phone's code first: in NetPermit, the gear, Plans, under "Have a code?".
    • Any phone. Works on every phone it reaches until it stops: after 48 hours, or after the time you choose, from 5 minutes to 365 days. Send it to one person. Never post it.
    • Short times. A time in whole days works with every build. Any other time, such as 10 minutes or 1 hour, goes by the clock of the phone that uses the code, and that phone needs NetPermit build 10003 or newer.
    • Once per phone. A phone accepts a code one time. The 7 days, 30 days or year start when the code is used, not when you make it. If the app is erased and installed again, a code that has not stopped works again on that phone.
    • Sent is sent. A code cannot be cancelled. For anything valuable, above all a permanent gift, choose One phone only.
    • Gifts, not sales. Google requires anything sold in the app to go through Google Play.

    Why can a code for any phone not work just once? NetPermit has no server, so nothing can remember that a code was already used on someone else's phone. One phone only is how to get "once".
